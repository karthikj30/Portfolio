# Project cover images

Drop project screenshots/covers here (e.g. `vendorconnect.png`, `itihaas.jpg`).

Then reference them in `src/data/portfolio.ts` on a project entry:

```ts
{
  name: "VendorConnect",
  date: "Sep 2025 – Jan 2026",
  stack: "Python · OpenAI · Android",
  description: "...",
  image: "/images/projects/vendorconnect.png", // <- this line
}
```

Recommended size: ~800×1000px (portrait-ish), under ~300 KB. JPG or PNG.
